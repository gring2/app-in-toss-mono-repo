# 친구렌즈 브랜드 결정

## 선택한 이름

`친구렌즈`는 “친구의 시선으로 나를 본다”는 제품 경험을 짧고 구체적으로 설명합니다. 초대 링크를 받은 사람도 심리검사보다 가벼운 자기이해 서비스라는 점을 바로 알아볼 수 있고, 렌즈가 겹치는 아이콘 모티프와도 자연스럽게 연결됩니다.

## 검토한 이름

| 후보      | 장점                                     | 제외 이유                                  |
| --------- | ---------------------------------------- | ------------------------------------------ |
| 친구렌즈  | 기능이 바로 이해되고 시각 자산과 잘 맞음 | 최종 선택                                  |
| 나봄      | 짧고 부드러움                            | 동일·유사 이름의 기존 건강 서비스가 확인됨 |
| 친구미러  | 비교 경험이 직관적임                     | 현재 서비스 `MirrorMe`와 연상이 가까움     |
| 겹쳐본 나 | 두 관점의 비교를 잘 표현함               | 앱 이름으로는 길고 검색·구전이 어려움      |
| 친구눈에  | 의미가 명확함                            | 문장형이라 브랜드 고유성이 상대적으로 약함 |

## 이름과 자산의 연결

아이콘은 파란색과 코랄색의 두 친구가 가운데 렌즈를 만드는 형태입니다. 공유 썸네일은 같은 인물 모티프, 익명 친구 세 명, 두 관점의 비교 카드를 한 장면으로 묶었습니다. 텍스트 없이도 “친구의 시선이 모여 비교 결과가 된다”는 핵심 흐름을 전달하는 것이 목표입니다.
